# Local review checklist

Nothing should be published until all items below have been checked in RStudio.

## Shiny application

* The app opens without an R error.
* Month, temperature, and wind controls update the graph.
* The reset button restores all filters.
* Hover details and zoom work in the Plotly chart.
* The prediction changes when temperature, wind, or month changes.
* The monthly table responds to the Explore filters.
* The How to use tab clearly explains the app and its limitations.

## Presentation

* The presentation contains exactly five slides including the title slide.
* The date is visible and current.
* The R code on slide four runs and displays output.
* No R warnings or errors appear.
* The left and right navigation controls are visible and work.
* Text and charts fit within each slide.

## After approval

* Create a public GitHub repository and push all source files.
* Deploy the Shiny application to shinyapps.io.
* Add the live app URL to the pitch and README.
* Publish the pitch on GitHub Pages.
* Publish the same pitch on RPubs.
* Verify every public link before submitting to Coursera.
